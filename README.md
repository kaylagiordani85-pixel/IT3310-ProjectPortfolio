Kayla Giordani  
IT 3310 – IT Project Management  
NovaTech Consulting Associate Consultant

This portfolio contains my work throughout IT 3310 as an Associate Consultant with NovaTech Consulting. Throughout the course, I will apply project management concepts and tools to a client engagement with Riverside Community Health Network (RCHN).

Riverside Community Health Network (RCHN) is a nonprofit health network that operates six community clinics across the Chicago metropolitan area. RCHN wants to replace its aging patient intake and scheduling system because the current system is creating problems for both staff and patients.

As an Associate Consultant with NovaTech Consulting, my role is to help evaluate and organize this effort as a project. This includes identifying what is currently known, determining what information is still needed, and helping develop an appropriate approach for completing the project.
