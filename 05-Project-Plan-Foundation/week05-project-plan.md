# Project Plan Foundation: RCHN Patient Intake and Scheduling System
**Consultant:** Kayla Giordani

**Role:** Associate Consultant, Project Manager, NovaTech Consulting

**Engagement:** Riverside Community Health Network (RCHN)

**Date:** October 6, 2026
---
## Scope
### In Scope, Phase One
Patient intake workflow standardization across all six clinics
Appointment scheduling system replacement
Staff training for the new system at all six locations
Mobile application for clinic staff
Billing system integration with the new scheduling data

### Out of Scope, Phase One
Initial rollout support for 90 days post-launch
Executive reporting dashboard for clinic leadership
Patient-facing online scheduling portal

### Scope Justification
I think the billing system integration with the new scheduling data is out of scope because though it helps streamline workflows it was not in the original scope. Including this would add more cost because you are building a separate system outside of what was intended. 

---
## SMART Objectives

### Objective 1
By the end of the project, implement a unified intake and scheduling system across all six RCHN clinics that allows Intake Coordinators to complete patient registration and scheduling within one system.

**Connection to Product Vision:** This objective supports the product vision by addressing the need for a unified system that reduces the number of separate screens and systems Intake Coordinators must use when preparing patients for visits.

### Objective 2
Within 90 days after implementation, reduce the average time required for Intake Coordinators to complete patient registration by 20% compared with the current process.

**Connection to Product Vision:** This objective connects to the product vision by measuring whether the unified system actually helps Intake Coordinators prepare patients.


---
## Planning Constraints
### Constraint 1
The new intake and scheduling system must be implemented across RCHN's six clinics.

**Effect on Planning:** This constraint affects scope and resources because the project team must plan for implementation across all six clinic locations rather than a single location.
